# Hibari for Misskey

HibariはiPhoneに特化して開発されたMisskeyクライアントです


### 大切にしていること

- 超なめらかな動作
  - ProMotion 120Hz で快適にタイムラインを閲覧
  - 心地よいアニメーションとフィードバック
  - 商業製品である大手SNSなみの触り心地の良さ
- オープンソースであること

### やらない / できないこと
- マルチプラットフォーム対応はしません。現時点ではiPad / Macへの対応も未定です
- Misskeyのフル機能に対応していく方針ではありません。あまり使わない機能は実装せず、必要に応じてWeb版を併用してもらう前提です
