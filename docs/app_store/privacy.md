# プライバシーポリシー

最終更新日: 2026年10月1日

このプライバシーポリシーは、iOS アプリ「Hibari for Misskey」（以下「本アプリ」）での利用者の情報の扱いについて定めるものです。

## 1. 開発者が集める情報

本アプリの開発・提供者（以下「開発者」）は、利用者の個人情報や利用状況を集めません。

- 開発者が運営するサーバーはありません。本アプリから開発者へ情報を送ることはありません
- 解析ツール、広告、トラッキングの仕組みは使っていません
- 他社のアプリやウェブサイトをまたいで利用者を追跡することはありません

ただし、利用者が iPhone の設定で「App デベロッパと共有」を有効にしている場合、Apple からクラッシュの情報などが開発者に提供されることがあります。これには利用者を特定する情報は含まれず、不具合の修正にだけ使います。

## 2. 本アプリが通信する相手

本アプリは、主に利用者がログインした Misskey サーバーと通信します。ノートの投稿、リアクション、通報など、本アプリでの操作はそのサーバーに送られます。

ノートに含まれる画像やカスタム絵文字などを表示するため、それらが置かれている他のサーバー（他の Misskey サーバーや画像の配信サーバーなど）から読み込むことがあります。

Misskey サーバーに送られた情報の扱いは、それぞれのサーバーの運営者が定めるプライバシーポリシーに従います。開発者は各サーバーを運営しておらず、サーバー上の情報を見たり管理したりすることはできません。

## 3. 端末に保存する情報

本アプリは、動作に必要な次の情報を利用者の端末の中だけに保存します。これらが開発者に送られることはありません。

- **アクセストークン**: Misskey サーバーにログインしたときに発行されるもの。iOS のキーチェーンに保存します
- **アカウントの情報**: ログインしているアカウントのサーバー、ユーザー名、アイコンなど
- **設定**: テーマ、最近使ったリアクションなど
- **キャッシュ**: 表示を速くするための画像などの一時的なファイル

ログアウトすると、そのアカウントのアクセストークンは端末から消えます。本アプリを削除すると、本アプリが保存した情報はすべて消えます。なお、サーバーに本アプリを許可したことは、Misskey の Web 版の「設定 → 連携」から取り消せます。

## 4. 端末の機能へのアクセス

- **写真**: 投稿に画像を添付するときに、利用者が選んだ写真だけを読み込みます。画像を保存するときは、利用者の許可を得て写真ライブラリに追加します

## 5. 対象年齢

本アプリの対象年齢は、App Store の本アプリのページに表示される年齢区分のとおりです。それより年齢の低い方は本アプリを利用しないでください。また、各 Misskey サーバーが定める利用条件（年齢の制限など）にも従ってください。

## 6. このポリシーの変更

このポリシーを変更するときは、このページで公開します。大きな変更をするときは、本アプリの中でもお知らせします。
