# サポート・お問い合わせ

## お問い合わせ

不具合、ご要望、不適切なコンテンツやユーザーの報告、プライバシーに関するお問い合わせは、次のメールアドレスまでお送りください。

**[hibari@hibari.yayugu.net](mailto:hibari@hibari.yayugu.net)**

不具合のご報告には、iPhone の機種と iOS のバージョン、Hibari のバージョン（設定 →「このアプリについて」）、ご利用の Misskey サーバー、起きたことと操作の手順を添えていただけると助かります。

## 不適切なコンテンツやユーザーを見つけたら

アプリの中で次のことができます。

- **通報**: ノートやプロフィールの「⋯」から「通報」を選ぶと、そのサーバーのモデレーターに届きます
- **ミュート・ブロック**: ノートやプロフィールの「⋯」から選べます。そのユーザーのノートはすぐにタイムラインから消えます

ノートやアカウントの削除などの対応は、各 Misskey サーバーの運営者が行います。Hibari の開発者はサーバー上のコンテンツを削除できませんが、ご連絡いただいた内容は確認し、必要に応じてサーバーの運営者にもお伝えします。

## よくある質問

**Hibari のアカウントは必要ですか？**
いいえ。お使いの Misskey サーバーのアカウントでログインします。Hibari 独自のアカウントはありません。

**Misskey のアカウントを作るには？**
Hibari ではアカウントを作れません。お使いになりたいMisskeyサーバーで先に登録してください。

**ログアウトするには？**
サイドメニューの「⋯」でアカウントの一覧を開き、「編集」からログアウトできます。サーバーに Hibari を許可したことは、Misskey の Web 版の「設定 → 連携」から取り消せます。
