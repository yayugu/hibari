# 利用規約

最終更新日: 2026年10月1日

この利用規約（以下「本規約」）は、iOS アプリ「Hibari for Misskey」（以下「本アプリ」）の利用条件を定めるものです。本アプリを利用する方（以下「利用者」）は、本規約に同意したうえで本アプリを利用するものとします。

## 1. 本アプリについて

本アプリは、Misskey サーバーに接続するためのクライアントです。本アプリの開発・提供者（以下「開発者」）は Misskey サーバーを運営していません。各サーバーの利用には、そのサーバーの利用規約やルールが適用されます。利用者はそれらにも従ってください。

## 2. 不適切なコンテンツと迷惑行為の禁止

本アプリでは、不適切なコンテンツや迷惑行為を一切容認しません。利用者は、本アプリを使って次のことをしてはなりません。

- 法令や公序良俗に反する内容の投稿
- 他人への誹謗中傷、嫌がらせ、脅迫、差別的な言動
- 暴力的・性的に過激な内容、またはそれらを未成年者に向けた投稿
- 他人の著作権、肖像権、プライバシーなどの権利を侵害すること
- スパム、なりすまし、詐欺などの行為
- 本アプリや Misskey サーバーの運営を妨げる行為

## 3. 不適切なコンテンツへの対応

不適切なコンテンツやユーザーを見つけたときは、本アプリで次のことができます。

- **通報**: ノートやプロフィールの「⋯」から、そのサーバーのモデレーターに通報できます
- **ミュート・ブロック**: そのユーザーのノートを表示しないようにできます

開発者にも [hibari@hibari.yayugu.net](mailto:hibari@hibari.yayugu.net) で報告できます。開発者は報告を受けたら 24 時間以内を目安に内容を確認し、必要に応じてサーバーの運営者に連絡するなどの対応をします。ノートの削除やアカウントの停止などの措置は、各サーバーの運営者が行います。
